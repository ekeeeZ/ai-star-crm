# AI Star CRM

Telegram-бот с CRM-системой для малого бизнеса.

## Возможности
- Приём заявок через Telegram
- Автоматические уведомления
- Веб-админка
- Аналитика и экспорт в Excel

## Установка
1. Клонируй репозиторий
2. Создай `.env` файл по образцу `.env.example`
3. Установи зависимости: `pip install -r requirements.txt`
4. Запусти: `python bot.py`

## Технологии
- Python + TeleBot
- Google Sheets API
- Flask
- Groq AI
